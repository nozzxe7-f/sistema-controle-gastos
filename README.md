# Sistema de Controle de Gastos

## Integrante
- Gabriel Roberto de Jesus Santos

## Problema
A dificuldade de acompanhar despesas pode fazer uma pessoa perder o controle do dinheiro disponível.

## Objetivo
Criar um programa simples em C para registrar despesas e acompanhar o orçamento.

## Tecnologias
- Linguagem C
- Compilador GCC (ou outro compilador C)

## Como executar
1. Abra o terminal na pasta do arquivo `controle_gastos.c`.
2. Compile: `gcc controle_gastos.c -o controle_gastos`
3. No Windows, execute `controle_gastos.exe`. No Linux, execute `./controle_gastos`.

## Funcionalidades
- Informar orçamento inicial.
- Registrar despesas.
- Consultar total gasto, saldo restante e porcentagem utilizada.

## Integração das disciplinas
- **Linguagem de Programação:** variáveis, tipos int e float, entrada e saída de dados.
- **Algoritmos e Programação Estruturada:** sequência, decisões com if/else e repetição com while.
- **Matemática Computacional:** soma das despesas, cálculo do saldo e porcentagem utilizada.
